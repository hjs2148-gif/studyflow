# Studyflow Next

시험일까지 **계획 → 실행 → 기록 → 평가 → 조정**이 끊김 없이 이어지는 학습관리 앱 MVP.
기존 `study flow/`(AI Studio 앱) 및 Daily Day와 완전히 분리된 독립 프로젝트입니다.

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트 (도메인·저장소·리듀서)
npm run build      # 타입체크 + 프로덕션 빌드
```

## 구조

```
src/domain/    순수 함수 (날짜, 계획 계산, 복습 간격, 분석, 목차 파싱) — UI 의존 없음
src/storage/   Repository 인터페이스 + localStorage 구현, 백업/가져오기, 데이터 검증
src/state/     순수 리듀서 + Context 스토어
src/ui/        TODAY / PLAN / FOCUS / INSIGHTS 화면과 공용 컴포넌트
src/styles/    단일 CSS (디자인 토큰, !important 없음)
```

## 핵심 설계 결정

- **저장 키**: `studyflow_next_v1`. 기존 `todait_v3`는 읽지도, 쓰지도, 지우지도 않습니다.
- **계획 3값 분리**: ① 최초 계획 ② 현재 진도 반영 필요량 ③ 학습속도 기반 현실 가능량. 데이터가 3회 미만이면 ③과 예상 완료일은 계산하지 않고 "기록 부족"으로 표시합니다.
- **자동 변경 없음**: 지연 시 종료일 연장/목표 축소를 *제안*만 하고, 사용자가 확인해야 반영됩니다.
- **오늘 목표 고정**: 오늘 공부해도 오늘 목표량이 줄어들며 흔들리지 않도록 '오늘 시작 시점' 남은 분량으로 계산합니다.
- **타이머 복구**: 시작 시각(epoch)을 저장하므로 새로고침/앱 종료 후에도 이어집니다. 12시간 넘으면 경고하고 기록 화면에서 시간을 직접 수정할 수 있습니다.
- **복습 간격**: 1→3→7→15→30일. 기억남 +1단계, 가물가물 유지, 잊어버림 1일로 초기화. 초기 운영 규칙이며 최적값이 아닙니다.
- **이해도**는 자기보고이며 객관적 점수로 취급하지 않습니다. 예측·평가 표본이 3건 미만이면 경향을 보여주지 않습니다.
- **손상 데이터**는 덮어쓰지 않고 별도 키로 격리 후 알립니다. 백업 가져오기 직전 현재 데이터를 자동 보관합니다.

## 구현 범위 (이번 커밋)

Phase 0 ~ 3 의 핵심: 시험/과목(분량·목차) 등록, 계획 계산, TODAY, 스톱워치 세션 + 예측/인출/이해도, 간격복습, INSIGHTS(판정→근거→행동), 학습기록 수정/삭제, 백업 내보내기/가져오기, PWA 매니페스트·오프라인 셸.

## 아직 구현하지 않음 / 한계

- 목표시간 타이머, 포모도로
- 단원(목차) 개별 수정 UI (현재는 추가·삭제만, 이름·목표량 수정은 삭제 후 재입력)
- 기존 로컬 V2.6.x(`todait_v3`) 백업 구조는 접근하지 못해 변환 미검증. 이 저장소의 `Task/Session` 형태만 best-effort 변환합니다.
- Firebase/Firestore 동기화 (Repository 인터페이스만 분리해 둠)
- 실제 기기(iOS/Android)에서의 검증, PWA 아이콘은 SVG 하나뿐
- 시간대 이동·서머타임 환경의 수동 검증
